# THERMORA website — first build

A responsive, single-page company website concept built with HTML, CSS and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `thermora_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page structure and content
- `css/style.css` — visual design and responsive layout
- `js/script.js` — mobile navigation and current year

## Notes
- The visual direction combines premium minimalism with natural, earthy colours.
- Photography is loaded from Unsplash, and fonts are loaded from Google Fonts, so those visual assets need an internet connection.
- The site intentionally describes THERMOWEAVE as a concept under research. It does not present untested performance, safety or cost claims as established facts.
- Replace the sample email address `hello@thermora.in` with an address you control before publishing.
- The enquiry link currently opens the visitor's email app. A real web form can be connected to a Flask backend in a later phase.
